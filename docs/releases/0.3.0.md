# Method Budget 0.3.0

A fuller Help menu, a command line named for the app, and Mac builds made for Apple
silicon. It also brings the saving and opening fixes that were ready for 0.2.1.

## Help when you need it

- **Report a Bug.** Help > Report a Bug… opens a new issue on GitHub with the version and
  your system already filled in. Nothing from your budgets is ever included.
- **The user guide, licences and the suite.** Help now has User Guide, Licenses and
  Notices (the app's licence and the third-party software it carries) and a link to the
  Method Production Suite. About Method Budget shows the licence too.

## The command line is `method-budget`

- **A name that says which app it is.** The command line is now `method-budget`, so it
  sits clearly beside the other apps in the suite. The old name, `method`, still works
  for now and prints a one-line note when you use it.
- **Coding agents and git keep working.** Agent setups and git merge driver settings that
  run `method mcp` or `method merge-driver` carry on unchanged and print no note. The
  agent server also speaks the newest version of the agent protocol.
- **Command line edits follow the app's rules.** Money typed on the command line rounds
  the way the app rounds it, and line fields and fringe changes are checked the same way.

## Fixed

- **Saving through a link keeps the link.** A budget opened through a symbolic link now
  saves into the file the link points to, instead of replacing the link with a copy.
- **The command line and shared folders save as carefully as the app.** Each save writes a
  complete new file before it replaces the old one, so a crash or a full disk mid-save
  never leaves half a budget or a stray temporary file behind.
- **Oversized files are refused.** A budget or a collaborator's change file larger than
  256 MB is turned away with a clear message instead of filling memory.

## Good to know

- **Mac builds are for Apple silicon from now on.** Intel Macs keep the version they
  have. Asking an Intel Mac to check for updates says so instead of reporting an error.
- **Updates now come from the Method Production Suite on GitHub.** The old address
  forwards there, so nothing needs doing.
- **Downloads have names without a version number**, such as Method-Budget-macOS.dmg, so
  a download link always points at the newest release.
- **Windows and Linux builds are included but not yet tested by hand**, and they don't
  update themselves yet.
- **The `method` name will go away in a later release.** Change scripts to
  `method-budget` when it suits you.
