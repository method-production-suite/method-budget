# Method Budget 0.9.0

People sharing a budget can turn on live changes: what each person types reaches the others
within seconds, and you can see which cell they are on. It is off until each person turns
it on.

## Live changes in a shared budget

- **Changes arrive within seconds.** In a shared budget, choose Turn On… on the Live
  changes row of the sharing status panel. Your changes reach the others who have it on
  within seconds, over an encrypted link between your computers, instead of waiting for
  the shared folder to sync.
  Anyone who leaves it off keeps working through the folder as before.
- **It says what it sends first.** Nothing connects until you turn it on, for yourself and
  for that budget. The notice that comes first says what leaves your computer: the
  addresses the others use to reach you, the changes you make, and the cell you are on.
  It is off again each time the budget opens.
- **See where the others are.** Each person with live changes on shows as an outline with
  their initials on the cell they are on. Go there takes you to that cell. Follow keeps
  your view with them as they move, until you press a key, click or scroll.
- **Your router is left alone.** The app doesn't ask your router to open a port. When two
  computers can't reach each other directly, the changes go through a relay, which passes
  them along encrypted and can't read the budget. A studio can name its own relay instead.

## Easier to use without a mouse

- **Focus comes back where you were.** When a dialog closes, focus returns to the button
  that opened it, even when the toolbar or panel behind it was redrawn.
- **The footer's totals are heard.** After an edit, a screen reader hears the nearest
  footer total along with the new net total. Selecting two or more lines reads out how many
  and what they add up to.
- **Dialogs fit their window.** A tall dialog in a small window now scrolls instead of
  running off the bottom, so its buttons can always be reached.
- **Sharing's colors are easier to read.** People's initials, the status dots and the
  conflict ring have stronger contrast, in light and dark mode.

## Fixed

- **The Linux AppImage opens.** On current Linux systems, 0.8.1's AppImage could open to
  an empty window. It now uses the computer's own graphics libraries.
- **The Tools panel's summary.** At the first start, the panel could show "That budget has
  been closed." beside the sample's own numbers. The message now clears once the summary
  loads.

## Good to know

<!-- live-changes:start -->
- **Live changes need 0.9.0 on each computer.** Members on 0.8 keep working with the same
  budget through the shared folder. They don't see live changes or cursors.
- **What the folder and the relay can see.** The addresses that reach your computer go to
  the other members through the shared folder, where the folder's hosting service can read
  them too. The relay sees which computers talk to each other and their addresses, never
  the budget.

- **Check your download.** The list of checksums for this release's files is now signed
  with the same key as the app's updates.
- **Mac builds are universal.** Windows and Linux builds are included but not yet tested
