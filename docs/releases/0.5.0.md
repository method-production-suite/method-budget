# Method Budget 0.5.0

A finished sample budget comes with the app: Field Station, an invented feature of about
a million dollars, built from a schedule and ready to explore.

## A sample budget to explore

- **Field Station opens at the first start.** Someone new to Method Budget, with no
  budgets of their own yet, starts in Field Station instead of an empty page. It is an
  invented independent feature on the low-budget feature chart: globals set from its
  schedule's days, fringes with cutoffs, one person paid in two accounts, groups, two
  lines in euros, an incentive estimate, a saved draft to compare against, dated notes
  and actuals through the second shoot week, all adding up to a net of 1,050,288.03.
- **Always a fresh copy.** The sample opens untitled, marked "Sample" on its tab. Change
  anything you like: nothing is kept unless you save it, and saved as a file it is yours.
- **Help > Open Sample** opens a new copy any time. Help > Open the Sample on First Launch
  turns the first-start sample off. Anyone who already has budgets of their own never sees
  it unasked.
- **The same budget everywhere.** The browser demo on the website and the pictures there
  now show Field Station too.

## Good to know

- **Checksums for every download.** Each release now lists the SHA-256 of every file it
  carries in a file called SHA256SUMS, so a download can be checked before it is
  installed.
- **Mac builds are for Apple silicon.** Windows and Linux builds are included but not yet
  tested by hand.
