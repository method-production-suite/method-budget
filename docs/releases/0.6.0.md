# Method Budget 0.6.0

Intel Macs are back: the Mac app runs on Intel and Apple silicon again, and an Intel Mac
still on 0.2 updates straight to this version. Budgets changed elsewhere are noticed more
reliably on Windows and Linux.

## One app for every Mac

- **Intel and Apple silicon.** The Mac download is one app that holds both kinds of code,
  so it runs natively on any Mac with macOS 11 or later. Versions 0.3 to 0.5 were for
  Apple silicon only.
- **Intel Macs catch up on their own.** An Intel Mac that stayed on 0.2 is offered this
  version at its next check for updates, or at once with Help > Check for Updates.

## Opening from the suite

- **Two command-line options for the app.** `--open-sample` opens the Field Station sample
  instead of the start window, and `--check-for-updates` checks for updates as Help >
  Check for Updates does. Method Launcher uses them; they also work from Terminal.
- **The recent list says when.** Each budget on File > Open Recent now remembers when it
  was last opened, so the suite's launcher can list your budgets newest first. A list from
  an earlier version is read once and kept, Mac bookmarks included.

## The sample, once

- **No switch for it any more.** Field Station opens once, at the very first start, and
  never again unasked. Help > Open the Sample on First Launch is gone; Help > Open Sample
  still opens a fresh copy any time. If you already had budgets of your own, you never see
  it unasked.

## Fixed

- **A change made elsewhere is noticed.** On Windows and Linux, a budget rewritten by a
  sync service or another computer moments after your own save, at exactly the same size,
  could go unnoticed. Now the content decides whenever the file's time can't.
- **The Windows build carries its files exactly.** The bundled charts of accounts and the
  sample are now byte for byte the same on Windows as on the Mac.
- **Agents see the same paths everywhere.** The agent server names files inside its
  folders with `/` on Windows too, so a path it lists can be passed straight back.

## Good to know

- **The message for a computer without an update changed.** Where no build exists for
  your computer, Help > Check for Updates now says "There's no update for this computer
  yet. This version stays as it is."
- **Windows and Linux builds are included but not yet tested by hand.**
